# DeepSeek Enhance Lite

基于 [Hiweny/deepseek-enhance](https://github.com/Hiweny/deepseek-enhance) 的**本地化修改版**。
本仓库**仅发布单一 `.user.js` 成品**，不包含原项目的 `src/` 源码树、`vendor/` 构建链、`android/` 套壳工程或 `harness/` 自测脚本。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 或兼容的用户脚本管理器。
2. 新建js脚本，将仓库脚本复制
3. 打开 [chat.deepseek.com](https://chat.deepseek.com)，脚本自动生效。

## 功能概览

本版本保留了原脚本 v8.5.0 结构的核心模块[reference:4]：

- **外观**：全局背景（URL / 本地图片、亮度 / 模糊可调）、水玻璃气泡、输入框磨砂、顶栏统一、Markdown 本地美化、离线 KaTeX 渲染。
- **对话**：思考自动折叠、代码块按行数折叠、右侧消息导航、上下文用量查看。
- **提示词**：按会话隔离的系统提示词，带预览与 `⟦DSE⟧` 标记包裹，历史接口回读时自动剥离。
- **隐私 / 防撤回**：SSE 流缓存 + 历史接口回放，智能模式 / 全量模式可选。
- **其他**：时间注入、页面缩放、设置面板四页签（外观 / 对话 / 提示词 / 其他）。

## 相对原版的详细改动

本版并非简单删减，而是围绕「轻量、稳定、不打扰原生交互」做了一轮系统性精简与重写。以下按改动区域逐项说明，涉及具体选择器与数值均来自当前成品脚本。

### 一、左侧会话侧边栏：从「半透明深色块」改为「统一磨砂玻璃」

原版侧栏在开启背景图后，会出现三类视觉断层：一是侧栏本体被一层半透明深色底覆盖，与背景图割裂；二是侧栏**底部**（用户信息区 / 底栏）残留一块不跟随磨砂的深色实心色块，形成明显的「下半截变暗」；三是侧栏内部的推荐卡片、快捷入口等元素各自带有 `background-color` 或 `bg-*` 工具类底色，叠在磨砂层上像贴了若干块深色膏药。

本版的处理：

- **侧栏本体统一为半透明磨砂层**：`.b8812f16.a2f3d50e` 由不透明背景改为 `rgba(255,255,255,.55)` + `backdrop-filter: blur(26px) saturate(160%)`，暗色下对应 `rgba(22,24,31,.55)`，与主聊天区的磨砂气泡同一套质感参数，明暗两套自动跟随 `body.dark`。
- **底部深色色块专项修复**：针对 `.b8812f16.a2f3d50e` 下的底部容器（`. _1d72f01`、末位 `div`、`.ds-scroll-area` 的 gutter 兄弟节点等）统一强制 `background-color / background-image: none !important` 并取消这些子层的 `backdrop-filter`，避免「磨砂叠磨砂」导致的二次变暗。侧栏底部现在与列表区是同一块连续的磨砂面，不再有横向的深色分界。
- **内部卡片 / 推荐区透明化**：侧栏内所有带 `style*="background-color: rgb"`、`bg-[#...]`、`bg-slate-*`、`bg-gray-*` 的元素统一透明化；`.rounded-lg` 类元素默认透明，仅在 `:hover` 时给一层 `rgba(127,127,140,.15)` 的微弱反馈底色。这样既消掉了「深色卡片突兀感」，又保留了可点击项的可辨识度，不会让按钮 hover 时完全无反馈。
- 侧栏滚动条、分隔线未做改动，仍沿用官网原生，避免过度定制导致与官网后续版本冲突。

### 二、视觉风格整体精简：从「多预设」收敛为「单一轻磨砂」

原版提供了「默认 / iOS 磨砂 / 水玻璃」三套气泡预设 + 顶栏「磨砂 / 背景透出」两种风格可切，选项多、CSS 分支多，实际使用中大部分用户只会停在某一套上，且多套并存时容易在明暗切换、超长消息展开等场景出现样式互相覆盖。

本版做了减法：

- **气泡只保留一款「轻磨砂玻璃」**：助手气泡 `.ds-markdown.ds-assistant-message-main-content` 固定为 `rgba(255,255,255,.65)` + `blur(14px) saturate(170%)` + 1px 半透明白边 + 内外双层阴影（外层投影 + 顶部 1px 高光内阴影），暗色下为 `rgba(30,33,42,.65)`；用户气泡 `.fbb737a4` 固定为强调色半透明 `rgba(59,108,246,.78)`。不再提供预设切换，减少设置面板复杂度与样式分支。
- **顶栏直接背景透出，不再叠磨砂**：`.the-header`、`._2be88ba` 一律 `background: transparent` 且 `backdrop-filter: none`，让背景图原样透上来，仅保留按钮本身的样式。原版顶栏磨砂层在背景图较花时会产生一条「灰带」，透出方案更干净，也顺带修掉了移动端分享按钮单独一块底色、标题区黑条的问题。
- **隐藏两类原生干扰元素**：`._0fcaa63`（AI 生成标识）直接 `display:none`；移动端顶栏「下载应用」按钮通过文本正则匹配（`/^\s*下载\s*(应用|APP|App)\s*$/`）打 `data-dse-hide` 隐藏，且**只在非分享页**（`/a/chat/s/` 之外）执行，不影响分享页的正常按钮。
- **强调色统一**：全部收敛到 `--dse-accent: #3b6cf6`（暗色 `#6b93ff`），链接、列表 marker、引用左边框、焦点环、导航按钮统一取这一个变量，避免原版多处硬编码色值导致的新旧色差。

### 三、底部空隙与操作栏：修复「最后一条消息被输入框吃掉」

这是原版（以及不少同类脚本）在开背景后最容易被忽略、但体感最差的问题：虚拟列表滚动到底时，最后一条 AI 消息底部的复制 / 重试 / 赞踩操作栏会滑进悬浮输入框背后，被输入框的半透明磨砂层遮住一半，看起来像「消息被切断了」。

本版的处理分两步，都属于纯 CSS 层修复，不动官网 DOM 结构：

- **给虚拟列表底部垫安全区**：对 `.ds-virtual-list-visible-items::after` 追加一个 `content:""` 的伪元素，`display:block; height:80px; width:100%; pointer-events:none`。这相当于在滚动内容末尾凭空多出 80px 空白，把整段内容「垫高」，最后一条消息的操作栏滚到底时正好停在输入框上方，不再被遮挡。80px 是按悬浮输入框（`._77cefa5`，`border-radius:22px` + 上下 padding）加安全间距估的，若你的输入框高度不同可微调。
- **操作栏可见度修复**：`._4f9bf79 > .ds-flex`（AI 消息底部操作栏容器）强制 `opacity:1`（原版部分场景会淡出到接近透明），并加 `margin-top:8px` 与气泡拉开距离；其内 `svg` 图标统一取 `--dse-text-2` 且 `opacity:.9`，避免和背景图融为一体看不见；`button:hover svg` 切到 `--dse-accent` 高亮。这样操作栏在任何背景亮度下都常驻可见、可点，同时不改变官网原生的按钮排列与功能。

另外，移动端输入框 `._77cefa5` 补了 `margin-bottom: max(12px, env(safe-area-inset-bottom))`，在刘海屏 / 手势条机型上不会贴底，输入框下方原本由背景透出的「渐变黑条」也一并清掉（`. _871cbca`、`.aaff8b8f` 背景透明）。

### 四、其他模块的精简与重写（简述）

- **思考区折叠**：由「模拟点击官网折叠头」改为**纯 CSS 折叠**（`.dse-think-open` 类控制 `.ds-think-content` 显隐，折叠头箭头用 `transform` 旋转）。这样长对话向上滚动、虚拟列表重挂载消息时，不会因为消息高度突变而出现「来回跳 / 一下冲到最开头」。用户手动展开后不再自动收起。
- **代码块折叠**：逻辑统一为「测量 `scrollHeight` 是否超过 `行数 × 行高 + padding`」，超过才挂折叠条；折叠只裁剪 `pre` 的 `max-height` 与 `overflow-y`，**不碰**官网原生的复制 / 下载按钮，折叠条颜色从 `pre` 的实际背景色采样（亮色代码块取深字、暗色取浅字），保证与代码区同色融合。
- **背景层结构**：`#dse-bg-layer`（图片 + `blur/brightness` 滤镜 + `scale(1.04)` 防边缘露白）+ `#dse-bg-mask`（`rgba(0,0,0,.2)` 遮罩）双层，`z-index` 分别为 `-2` / `-1`，`pointer-events:none`，不拦截任何点击。开启时给 `body` 加 `dse-has-bg`，由这一个类统一驱动侧栏、气泡、顶栏、输入框的「透明化 / 磨砂化」规则。
- **LaTeX**：内联离线 KaTeX，`$$` / `\[` / `\(` / `$` 四种定界符，`ignoredTags` 排除 `pre/code`，`ignoredClasses` 排除 `katex/mermaid`，流式结束后经 `MutationObserver` + 260ms 防抖统一渲染，解析失败 `throwOnError:false` 不炸排版。
- **消息导航**：只用右侧上下两个圆钮（移动端更小更淡），定位改用官网真实的内层虚拟列表滚动容器（`.ds-virtual-list.ds-scroll-area`，找不到时向上逐级找可滚动祖先），按消息在滚动内容中的偏移逐条定位，目标未挂载时先滚动一屏、460ms 后重试，命中后加 1.5s 的 `outline` 闪烁提示。
- **移除项**：Android 套壳（DeepSleep）全部 WebView 注入 / 键盘适配 / 分享联动逻辑、「深海女仆工坊」皮肤及其约 3.1MB 素材、`dist/inject.js` 注入版构建链、`harness/` Playwright 自测脚本、`tools/` 构建辅助，均不进入本成品。

## 兼容性

- 桌面端：Chrome / Edge / Firefox + Tampermonkey
- 移动端：Kiwi Browser / Edge Mobile / Safari（配合油猴扩展）
- 明暗主题自适应

脚本依赖 chat.deepseek.com 当前的 DOM 结构与接口。官网大版本更新后，个别选择器可能需要自行调整，原版集中维护在 `core/selectors.js`，本版为成品文件，需直接搜索对应选择器修改。
